**clipse** is a toy linker project. I'm learning about linkers so i'll be implementing stuff here. Inspired by the book CSAPP. The naming is inspired Pusha T and Malice's Clipse.

Commands:

- `make` builds `a.out` and `example/main.o` / `example/sum.o`
- `make run` builds everything and runs `./a.out ./example/main.o ./example/sum.o`
- `make clean` removes the built files
